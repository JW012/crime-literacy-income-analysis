# crime-literacy-income-analysis 

This project explores how income levels and literacy rates relate to crime rates across countries using 2015 data from the World Bank. It applies correlation analysis, regression modeling, and visualization techniques to investigate which socioeconomic variables best predict national crime levels.

## Features

- Data sourced via World Bank API
- Includes Spearman correlation analysis and log-transformed regression models
- Visualized findings using Plotly interactive charts
- Published using GitHub Pages
